CVP Laundry v1.4 update

1) Stop npm run dev with Ctrl+C.
2) Copy app/globals.css and components/Dashboard.tsx over the same paths in C:\Users\Administrator\Desktop\Laundry-webapp
3) Run: npm run build
4) If build passes, run:
   git add .
   git commit -m "Add laundry rules and announcements"
   git push
5) Vercel will deploy the update automatically.
